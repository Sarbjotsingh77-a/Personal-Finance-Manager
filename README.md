# Personal-Finance-Manager
The Personal Finance Manager is a command-line based Python application that helps users track daily expenses, store data persistently using CSV files, generate analytical reports, and manage backups. The system follows Object-Oriented Programming, modular design, and robust error handling to ensure scalability and maintainability.

A command-line Python application to manage personal expenses with CSV-based persistence.
## Features
- Expense tracking
- Category-wise reports
- Data backup
- Error handling & validation

## Installation
1. Clone repository
2. Install Python 3.x
3. Run:
   python main.py

## Technologies Used
- Python
- CSV module
- OOP
